# AGENTS.md

## Overview
WordPress (Bedrock) ベースの Web サイト

## Development

### Language & Frameworks
- PHP
- WordPress (Bedrock)
- Docker

### Setup
```bash
composer install
npm install
docker-compose up -d
```

### Code Style
- 日本語でコメント・ドキュメントを記述
- 既存コードスタイルに従う

### Testing
```bash
npm test
```

## GitHub Project での作業管理

- この repo の作業は GitHub Project（`.github/scrum-board.yml` の番号）で管理する
- 次にやる物と、課題の起こし方は `.agents/skills/scrum-board/SKILL.md`
- Status は Backlog / In progress / In review / Done の 4 つ。Todo は作らん
